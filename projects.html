Projects

Contributions to open-source tools, then my own public code. Research code built on unpublished lab data stays private until the work is published.

Contributions to open-source tools

  • pyRiemann #476 (merged): added transport_wasserstein, parallel transport under the Bures-Wasserstein metric.
  • pyRiemann #478 (merged): replaced an array-api-extra helper with the namespace-native expand_dims.
  • NeuroDOT #8: reported that TtestWelch returned a one-tailed p-value although documented as two-tailed; the maintainers made the two-tailed test the default.
  • CEBRA #309 (in review): chunked the top_k search in OrthogonalProcrustesAlignment; peak memory on a 15000 x 15000 alignment fell from 5372 MB to 621 MB with bit-identical results.
  • NeuroDOT_py #5 (in review): an exact cached dense reconstruction path, with benchmarks.
  • NIRFAST #22 and #23 (in review): Apple Silicon support, and a fix for integer precision loss when saving large meshes.
  • openlifu-python #476 (in review): ported the lps2sph and sph2lps coordinate transforms from MATLAB.

Research and teaching code

  • dot-qc-simulator: a marimo app that teaches DOT/fNIRS quality-control plots. Physics-based synthetic two-wavelength data on an HD-DOT cap (Farrell diffuse reflectance, modified Beer-Lambert law), with artifacts added one slider at a time.
  • pushing-bigred-gpu-limits: benchmarks of GPU optimization techniques on Indiana University's Big Red 200 (4x A100 nodes).
  • iu-hpc-agent: a reference for Indiana University's Big Red 200 and Quartz clusters (SLURM, modules, job recipes), checked against the clusters, packaged for AI coding agents.

Explainers and tools

  • 3brown1blue: generates 3Blue1Brown-style Manim explainer videos from topics or slide decks.
  • manim-attention: an animated explainer of "Attention Is All You Need", built in Manim.
  • marginalia: a blog I write by hand on a reMarkable tablet.
  • paper2kindle: search academic papers and send them to a Kindle.
